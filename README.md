## Tentang Green Sea

> **Green Sea** adalah website penyedia layanan jasa pembuatan website yang dapat di akses dengan mudah.

- Tujuan? `Memberikan jasa`
- Untuk? `Untuk pelanggan yang ingin berbisnis atau lainnya`
- Khusus pembisnis? `Tidak`
- Harga mahal? `Tidak, harganya murah`
